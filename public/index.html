🔑 Worker Passbook & Privacy Key Policy

Every worker has a confidential 5+ digit secret key to access their own passbook, wage slip, and attendance records on mobile. This guarantees zero peer snooping.

• Default Password: 12345 is automatically assigned to new or existing workers unless customized.
• Worker Self-Service: Workers can change their password directly inside their mobile passbook using the 🔑 Change Key option.
• Admin Override: If a worker forgets their secret key, employer/admin can reset it anytime by editing the worker profile in the Workers tab.
• Minimum Complexity: Minimum 5 digits / characters required by security policy.
